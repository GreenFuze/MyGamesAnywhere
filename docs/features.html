The MGA approach

Easy to browse. Honest underneath.

MGA groups a fragmented collection into games you recognize while preserving the copies, editions, platforms, add-ons, files, and services that make each entry playable.

One game, several copies

See Steam, Xbox, ROM, installer, and cloud copies together. Group by connection when you want the same game to appear in each relevant collection.

A Play button with choices

Set a sensible default, then use the arrow for installed, storefront, emulator, browser, cloud, or remote-device alternatives.

Multiple emulators

A platform can offer several emulators. MGA can pick a default while exposing capability differences such as RetroAchievements support.

Real variants stay real

Regional releases, remasters, “Windows 10” editions, DLC, and similarly named games remain distinct when their identity or compatibility differs.

Profile-owned connections

Storefront and cloud credentials, scans, favorites, achievements, and library state belong to the profile that created them.

Device-aware installs

Install state, available space, prerequisites, and two-stage progress are reported for a specific device and Windows user.

Save compatibility matters

MGA treats compatible saves as an explicit capability. It does not assume two editions or emulators can safely share the same files.

Actionable attention

Notifications name the affected game or connection, explain what changed, and link to the action that can resolve it.

Automatic library refresh

Background scans and Rescan all share the same reconciliation path, including removals, restored games, history, and visible status.

Achievements by provider

Xbox, Steam, and RetroAchievements progress stays attached to the relevant copy and provider instead of becoming one misleading score.

Manual repair tools

Split a wrong grouping, merge a missed match, search again, re-detect, review duplicates, or mark content as an add-on.

Local-first ownership

The library database, media, server configuration, bindings, and managed installs stay on hardware you control.

What a game page should answer

No archaeology required.

  • Where did I get this game?
  • Which editions or platforms do I have?
  • Can it play in this browser or on this device?
  • Is it installed, and who manages that installation?
  • Are achievements and compatible saves available?
  • What can I do if MGA matched it incorrectly?
