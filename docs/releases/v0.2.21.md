# v0.2.21 Release Notes

`v0.2.21` makes it possible to connect Xbox — or any provider that needs a
sign-in — to a server running on another machine.

## Signing in to a server on another computer

Providers only accept sign-in redirects to addresses registered with them in
advance, and for Microsoft and Google those are `localhost` and `127.0.0.1`. So
when the sign-in finishes, the browser is sent back to *the machine it is
running on*. If the console is open against a server on a different computer,
the sign-in arrives at the wrong one and the right one never hears about it. It
shows:

> Authentication failed: OAuth state is missing, expired, or was already used

Nothing has expired. The sign-in simply went to the wrong address.

Starting a sign-in now offers a field to paste that address into. Complete the
sign-in as normal, and if the tab shows an error, copy the whole address out of
it and paste it back into the console. The server checks it against the sign-in
it started and finishes the connection.

The field appears as soon as a sign-in begins rather than after one fails,
because by the time it fails you are looking at an error page with no way to
know the option exists.

## Upgrade and migration notes

- No migrations, and no change to how a sign-in is started or which addresses
  providers are asked to use. This only adds a way to hand back an address that
  arrived somewhere else.
- The in-app updater applies this release: check, download, verify, install,
  restart.
