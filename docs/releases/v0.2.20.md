# v0.2.20 Release Notes

`v0.2.20` stops the library accumulating records for games that no longer
exist, and takes a misleading number off the Library page.

## Games that are gone now leave

A scan that no longer sees a game used to mark the record missing and leave it
there forever. Nothing removed it, so the count only grew — on one library, 841
records, most of them files deleted from a cloud drive months earlier. The
"Validate files" button could not clear them either, because it only examined
records the library still showed.

A record is now deleted once **three consecutive scans agree it is gone**. The
count resets the moment a scan finds it again, so a drive that drops in and out
never costs you a game.

Two conditions must both hold before anything is deleted:

- The connection can prove a file is gone. That means a connection that reads a
  filesystem — a cloud drive, a network share, a local folder. A storefront
  reports what an account has, not what is on a disk, so its games are never
  removed this way.
- The connection returned a library this time. A connection that answers with
  nothing is far more likely to be broken than to be a drive that emptied
  itself between two scans, and MGA will not delete anything on that answer.

That second condition is not theoretical. A signed-in storefront connection
answered two consecutive scans with an empty list and no error at all, and
every one of its 99 games was marked missing until the next scan brought them
back. Nothing should be deleted outright on an answer like that.

Records that were already missing when this release is installed start their
count from zero, so nothing is removed on the strength of scans that ran before
MGA was counting.

## "Missing right now" is gone from the Library

The number added together three unrelated things — records a source stopped
returning, entries marked as not a game, and files nothing could identify — and
called all of them missing. Records now retire themselves, so there is nothing
left to act on.

## Upgrade and migration notes

- Migration 42 adds one column to the source game table, defaulting to zero. It
  is additive and runs through the backup-first migration flow.
- The in-app updater applies this release: check, download, verify, install,
  restart.
