# v0.2.22 Release Notes

`v0.2.22` makes updates install reliably, lets an application sign in without
anyone issuing it a key by hand, and gives every game in the library an icon.

## Updates install reliably

The update download ran inside a single web request, which this server cuts off
after a minute. An installer is well over 100 MB, so an update only installed if
the connection happened to be fast enough for the whole transfer — and it got
harder as MGA grew. One server reached 85% and was cut off.

The download now runs on its own and reports progress as it goes, so it takes
however long it takes. Nothing about the screen changes; it already showed a
progress bar.

## Applications sign in with a player and password

Connecting something like Playnite meant opening this console as an
administrator, issuing an access key by hand, and copying it across.

An application can now ask a server which players it has, and sign in as one of
them with that player's own password. The server hands back an access key
limited to reading the library, its artwork and its content — nothing else — and
that key appears in **System → Connected apps** where it can be revoked without
anyone changing a password. The application keeps the key, never the password.

Any player can do this, not only an administrator: allowing something to read
your own library is not an administrative act.

## Every game carries an icon

The library list a connected application reads had a cover but no icon, so
applications showed a blank space beside every game. It now carries one, using
the game's logo where there is no icon. The MGA console is unchanged.

## Upgrade and migration notes

- No migrations.
- The in-app updater applies this release: check, download, verify, install,
  restart. This is the first release whose own download is no longer bounded by
  the request timeout.
