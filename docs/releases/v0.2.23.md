# v0.2.23 Release Notes

`v0.2.23` makes the repair introduced in v0.2.22 actually run.

## Games MGA found but never showed

v0.2.22 added a repair to the scheduled run: games no metadata source could
identify are retried, so they can appear in the library on their own. It did not
work. The repair ran without knowing which player's library it was repairing,
so the first thing it asked for was refused and the run ended — quietly, after
every scan.

It now runs properly. On the library it was found on, the first corrected run
identified 74 of 79 games that had been sitting on a drive and shown nowhere,
including a whole arcade collection.

If your library grows after installing this, that is why: those games were
already there.

## Upgrade and migration notes

- No migrations.
- The in-app updater applies this release: check, download, verify, install,
  restart.
