# v0.2.19 Release Notes

`v0.2.19` is a console release. The Library became something you can actually
search, narrow and correct, the System page started answering the questions you
would otherwise open a log file for, and signing in to Steam works again.

## Library

- Search and sort, with counts that match what is on screen rather than the
  number of rows behind it.
- The pictures MGA had already downloaded are shown, a game can be favourited,
  and a cover can be chosen from that game's own pictures.
- Narrow the library by source or by platform. Each choice carries the number of
  games it would show, and that number is the same one the list then shows.
- A source can be moved out of the wrong game and into the right one, merged
  back, or the move undone.
- Every badge carries a picture, and provider and platform marks use the real
  logos.
- Games a rented catalogue no longer carries are left out by default. A
  subscription source reports what an account has played, not what it owns, so
  it lists titles that were tried once and cannot be started today without
  buying them. A game is left out only when a subscription provider reported it,
  that subscription does not carry it now, and nobody unlocked an achievement in
  it. The page says how many it removed and brings them back in one click,
  because the rule can be wrong from the outside: a game bought outright and
  never played looks exactly like a lapsed subscription title.

## System

- Which address and port this server answers on, editable, written to the
  configuration file with a backup kept beside it.
- The server log, tailed on the page and downloadable whole.
- Backup state, artwork download state, and what each plugin is and what it
  needs.

## Steam

- The Steam library is read with the signed-in account token rather than a
  publisher API key, so a library scan works with no key at all.
- QR sign-in is back. It had been removed as collateral in an earlier change and
  went unnoticed because nothing failed to compile; a test now asserts the panel
  is still reachable.
- A connected account says who it is signed in as.
- Achievements still use the publisher API key, because Steam's achievement
  endpoints reject an account token outright. Only achievements need the key;
  the library does not.

## Upgrade and migration notes

- No migrations. This release adds no schema or persisted-record change, so the
  updater carries the database across untouched.
- The in-app updater applies this release: check, download, verify, install,
  restart.
