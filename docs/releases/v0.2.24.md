# v0.2.24 Release Notes

`v0.2.24` is about games and pictures that were there all along and shown nowhere.

## Games MGA could not name now appear on the Library page

A game that no source can identify never becomes a library entry, and until now
nothing said so. On the library this was found on, that hid 75 games — 48 of
them an entire arcade collection — and the only symptom was a library that felt
smaller than the drive it came from.

The Library page now lists them, above the game list rather than below it,
because someone who cannot find a game looks at the list first and concludes it
is gone. There is a button to retry them immediately; it reports how many it
managed to name rather than merely that it finished. The scheduled run already
retries them on its own, so most resolve without anyone pressing anything. The
panel hides itself when nothing is waiting.

## Artwork the downloader gave up on is dealt with

"Gave up on: N" only ever grew. Nothing revisited a permanently failed image, so
the console reported a number no one could act on.

The scheduled run now handles them. An image no game references is deleted —
nothing can show it and there is no game to ask a source for a replacement. An
image a game still wants is handed back to the downloader to try again, up to
three times, because a temporary server error deserves another attempt and a URL
that has failed three times will not start working.

## Upgrade and migration notes

- No migrations.
- The in-app updater applies this release: check, download, verify, install,
  restart.
