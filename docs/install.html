Install on Windows

Start with the server. Add clients where you play.

The MGA Server hosts your library and web interface. The MGA Client is a small, windowless tray app that installs and launches games for one Windows user.

Download latest release Set up a device

Before you begin

  • Windows is the supported packaged platform today.
  • The default web address is http://127.0.0.1:8900.
  • LAN access is intended for a trusted home network.
  • MGA is pre-1.0; keep a backup of its data directory.

Step 1

Choose how the server runs

For me only

Best for a personal PC. MGA starts after you sign in and listens only on that computer by default. No administrator approval is needed for normal server use.

All users

Best for an always-on household server. MGA runs as a Windows service, can serve the trusted LAN, and requires administrator approval during setup.

Portable ZIP

Best for evaluation or a self-contained setup. Extract it to a writable folder such as C:\Games\MGA and run Start MGA.cmd.

Step 2

Open MGA and create the first profile

  1. Open http://127.0.0.1:8900 on the server PC.
  2. Create the first admin profile. The initial password is changeme; change it immediately.
  3. Add family profiles as needed. A PIN needs at least four digits; a password needs at least four characters.
  4. Add each person's stores and folders from Settings → Connections. Connections and credentials belong to the active profile.

Opening MGA from another device

All-users installs can be opened using the server name or LAN address, for example http://tv-room:8900. Plain HTTP is supported for trusted LANs. Do not expose the server directly to the public internet.

Step 3

Pair the PCs that install or play games

  1. On the target PC, open MGA and use the client control in the top bar.
  2. Choose Download if the MGA Client is not installed.
  3. After installation, choose Run or Run as administrator. The elevated choice lasts until the client exits or Windows restarts.
  4. Choose Pair and approve the device for the current profile when prompted.
  5. A green client indicator means this browser can reach the client for its current Windows user.

Why one client per Windows user?

Local game access belongs to both the computer and the signed-in Windows user. This avoids running a permanent privileged service and lets another user pair their own client independently.

The same client can bind to more than one MGA Server. Each server receives a separate managed root so one server cannot silently overwrite another server's files.

Updates

Download and apply in one flow

MGA checks periodically for releases and notifies an admin when one is available. Settings can download, verify, apply, and restart the server. A downloaded update can also be applied later or downloaded again.

Where data lives

For me only: app files under %LOCALAPPDATA%\Programs\MyGamesAnywhere; data and logs under %LOCALAPPDATA%\MyGamesAnywhere.

All users: app files under %ProgramFiles%\MyGamesAnywhere; data and logs under %ProgramData%\MyGamesAnywhere.

Portable: mutable data remains inside the extracted folder and is preserved during a verified portable update.
