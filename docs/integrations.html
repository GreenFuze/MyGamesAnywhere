Stores, subscriptions, and game folders

ConnectionStatusWhat it brings into MGAWhat you need
SteamSupportedYour owned and Steam Families games, plus achievementsA Steam Web API key and the Steam account details requested by MGA
Xbox / PC Game PassSupportedYour Xbox library, Game Pass and xCloud availability, and achievementsSign in with the Xbox account for this player
Epic GamesExperimentalEarly Epic library discovery; do not expect a complete launch or install workflow yetThe connection details shown by the experimental setup
Google DriveSupportedGames, archives, installers, and browser-play files stored in DriveSign in and choose the folders you want MGA to see
NAS / SMB foldersSupportedGames, archives, and installers kept on shared storageThe share address and, if needed, its username and password

ROMs and installers are content inside a configured Google Drive or SMB/NAS connection; they are not separate account connections. MGA does not include games, ROMs, firmware, or store entitlements.

Achievements and saves

Follow achievements from Steam, Xbox, and RetroAchievements. Save sync is still a bounded foundation: MGA should only offer it where the source, destination, and game versions are known to be compatible.

  • Steam and Xbox progress stays with the correct account and game version
  • RetroAchievements can add goals to supported classic games
  • EmulatorJS save states and save RAM can sync through MGA
  • MGA only offers save sharing where the formats are known to be compatible
