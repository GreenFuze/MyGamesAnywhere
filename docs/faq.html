FAQ

Questions people ask before trying MGA.

Is MGA a Playnite alternative?

It can be. Playnite is a mature, customizable desktop launcher. MGA is aimed at households that also want a web interface, several devices and profiles, and multiple concrete copies and play options kept distinct.

Is MGA a LaunchBox alternative?

Partly. LaunchBox is strong at collection presentation and emulation. MGA focuses on web access, device control, profile separation, and keeping each copy's source, install state, achievements, and play options visible.

Does MGA replace Steam, Xbox, or Epic?

No. MGA connects to those services and presents their games alongside the rest of your collection. Purchases, downloads, and service-specific actions still rely on the original service.

Does MGA store my data locally?

Yes. MGA is local-first. The database, media cache, config, and plugins live on your machine unless you explicitly configure sync integrations.

Can MGA handle ROMs and emulators?

Yes. ROM and emulator-style collections are part of the core product direction alongside storefront, cloud, and file-backed sources. Browser-play surfaces include EmulatorJS, js-dos, and ScummVM where configured.

Can one game have multiple playable copies or versions?

Yes. MGA can group the copies for browsing while keeping the Steam, Xbox, regional ROM, remaster, or other concrete version available as its own play option.

Can achievements differ by source or platform?

Yes. Achievement sets remain attached to their provider and copy, so an arcade version and a console version can show different progress.

How does browser play work with cloud or network files?

MGA first prepares remote or network files in a local cache. The browser runtime can then load a ready local copy instead of repeatedly reading small files from Drive or SMB.

Does save sync work inside EmulatorJS?

MGA can route EmulatorJS save states and save RAM through its save-sync cache when a compatible save connection is active.

What happens when detection is wrong?

MGA puts the item in a visible review list. You can try detection again, search for the correct game, apply a better match, split or merge copies, or identify add-on content.

Can MGA delete files it identified incorrectly?

For supported file connections, yes. MGA first shows the exact files that would be affected and requires confirmation. Google Drive files move to Drive trash; SMB cleanup is limited to explicit file targets.

Can I inspect where a game came from?

Yes. A game page can show its connections, copies, files, folders, provider links, and technical matching details.

Does MGA support Game Pass and xCloud launch surfaces?

MGA can surface Game Pass and xCloud availability through Xbox-backed data where the connected source exposes it.

Does MGA expose an API?

Yes. MGA exposes a local REST API and a React frontend over the same local library.

Is MGA Windows-only right now?

The current packaged release is Windows-first and includes a portable ZIP plus an installer. Cross-platform installers are planned later.

Can MGA listen on my LAN?

Yes. A personal or portable setup can remain on 127.0.0.1:8900; an all-users install can serve a trusted LAN. Plain HTTP is supported for private LAN use. Do not expose MGA directly to the public internet.
