FAQ

Questions people ask before trying MGA.

Is MGA a Playnite alternative?

It can be. Playnite is a mature, customizable desktop launcher. MGA is aimed at homes that also want a browser interface, several gaming devices and players, and every store version and way to play kept clear.

Is MGA a LaunchBox alternative?

Partly. LaunchBox is strong at collection presentation and emulation. MGA focuses on opening the library from any screen, controlling several PCs, separating each player's accounts, and showing where every version can be played.

Does MGA replace Steam, Xbox, or Epic?

No. MGA connects to those services and presents their games alongside the rest of your collection. Purchases, downloads, and service-specific actions still rely on the original service.

Does MGA stream games from my gaming PC?

No. MGA is not a general PC game-streaming service. It can offer configured browser-emulator routes and show xCloud availability supplied by an Xbox connection.

What can MGA install today?

Managed installation is currently limited to ZIP, 7z, and RAR archives plus a bounded flow for signed GOG Inno installers. Storefront-owned installs and updates still belong to their original apps, and arbitrary EXE or MSI installers are not supported.

Does MGA store my data locally?

Yes. MGA runs on your hardware. Your library, artwork, settings, and connections stay on your MGA Server unless you choose to connect a sync service.

Can MGA handle ROMs and emulators?

Yes. ROM and emulator-style collections are part of the core product direction alongside storefront, cloud, and file-backed sources. Browser-play surfaces include EmulatorJS, js-dos, and ScummVM where configured.

What if I own the same game in more than one place?

MGA can show Steam, Xbox, regional ROMs, remasters, and other editions together while keeping every version available in the Play menu.

Can achievements differ by source or platform?

Yes. Achievements stay with the store or platform that awarded them, so an arcade version and a console version can show different progress.

How does browser play work with cloud or network files?

MGA first prepares remote or network files in a local cache. The browser runtime can then load a ready local copy instead of repeatedly reading small files from Drive or SMB.

Does save sync work inside EmulatorJS?

MGA can route EmulatorJS save states and save RAM through its save-sync cache when a compatible save connection is active.

What happens when detection is wrong?

MGA puts the item in a visible review list. You can try again, search for the correct game, choose a better match, separate versions that do not belong together, or mark add-on content.

Can MGA delete files it identified incorrectly?

For supported file connections, yes. MGA first shows the exact files that would be affected and requires confirmation. Google Drive files move to Drive trash; SMB cleanup is limited to explicit file targets.

Can I inspect where a game came from?

Yes. A game page can show its stores, versions, files, folders, and the details MGA used to recognize it.

Does MGA support Game Pass and xCloud launch surfaces?

MGA can surface Game Pass and xCloud availability through Xbox-backed data where the connected source exposes it.

Does MGA expose an API?

Yes. MGA exposes a local REST API and a React frontend over the same local library.

Is MGA Windows-only right now?

The current packaged release is Windows-first and includes a portable ZIP plus an installer. Cross-platform installers are planned later.

Can MGA listen on my LAN?

Yes. A personal or portable setup can remain on 127.0.0.1:8900; an all-users install can serve a trusted LAN. Plain HTTP is supported for private LAN use. Do not expose MGA directly to the public internet.

Can I use MGA away from home?

Not as a supported direct-internet setup today. The current release is designed for one PC or a trusted home network.

Why is the Server download much larger than the Client?

The current pre-1.0 Server package includes the web interface and offline browser-play runtimes. The Client is a small Windows tray app, so its download is much smaller.
